---
name: blender-turntable
description: "Generate 360-degree turntable camera animation and render loop in Blender"
---

Execute automated product camera animation in Blender via MCP:

1. Connect to Blender MCP.
2. Select target model in current scene.
3. Configure camera movement (`turntable`, `dolly-rotate`, `crane-shot`, `slow-zoom`, `dynamic-full-loop`, `perfect-loop`).
4. Set parameters (duration, fps, lighting, background transparency).
5. Render video animation to `~/Desktop/Blender Videos/` (or target path).
