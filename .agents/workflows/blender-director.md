Orchestrate Blender 3D production pipeline using the installed `blender-director` skill and Blender MCP:

1. Confirm Blender 5.0.1 connection via Blender MCP (`localhost:9876`).
2. Plan production lifecycle:
   - Discipline routing (`hard-surface`, `prop-artist`, `character-artist`, `environment-artist`)
   - Style direction (`realistic-style`, `lowpoly-style`, `anime-style`, `horror-style`, etc.)
   - UV unwrapping (`uv-workflow`), PBR materials (`materials`, `texture-workflow`)
   - Lighting and camera staging (`lighting`, `camera-cinematography`)
   - Optimization & validation (`asset-optimization`, `qa-review`)
   - Game engine export (`godot-export`, `unity-export`, `unreal-export`, `export-pipeline`)
3. Execute and verify scene directly inside Blender.
